# Changelog

All notable changes for `agentic-proteins` are recorded here.

## 0.2.4 - 2026-04-06

### Added

- Deterministic runtime, artifact-first execution flow, and replay-oriented run
  records for protein design workflows.
- Package-local CLI and API surfaces with shared runtime contracts.
- Provider integration contracts for local and remote model workflows.

### Changed

- Expanded coverage and quality gates for runtime, providers, and execution
  lifecycle behavior.
