# Domain Language

Stable package language matters because `bijux-proteomics-foundation` is easier to review when
its key terms do not drift into neighboring package vocabulary.

## Terms To Keep Stable

- `identifier`
- `schema compatibility`
- `deterministic serialization`

## Language Test

If a term makes it harder to say whether work belongs in `bijux-proteomics-foundation` or in
bijux-proteomics-core, change the term or move the work.

## First Proof Check

- this package handbook
- neighboring package handbooks for conflicting ownership language
