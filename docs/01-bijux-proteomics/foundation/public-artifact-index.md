# Public Artifact Index

The public artifact index exists so a skeptical reader can open the strongest
current flagship surfaces without reverse-engineering the repository package
tree first.

The index is organized around the surfaces that matter most:

- the flagship release-candidate page
- the elite readiness scorecard
- one outsider packet per flagship workflow family
- one independent rerun dossier per flagship workflow family
- one external review kit per flagship workflow family

## Why This Exists

Without a stable artifact index, the repository can still ship real evidence
while making the review path feel harder than the claim language. That is an
honesty failure. The index keeps the opening order visible before a maintainer
starts narrating what the reader should trust.
