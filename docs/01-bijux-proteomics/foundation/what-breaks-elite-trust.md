# What Breaks Elite Trust

Repository-wide elite language is still blocked, but today already has a real
bounded trust surface. This page explains what would weaken that surface
tomorrow.

## Current Fragility

- if the public artifact index drifts, the review path becomes maintainer-memory
  dependent again
- if a workflow family loses its companion rerun dossier, its current bounded
  outsider-auditable sentence falls back toward one-package optimism
- if a workflow family loses its external review kit, the same claim becomes
  harder for one outsider to challenge directly from shipped files

## Why This Matters

The current proof boundary is narrow. That is acceptable. What is not
acceptable is letting the narrow proof boundary become harder to inspect than
the wording is to publish.
