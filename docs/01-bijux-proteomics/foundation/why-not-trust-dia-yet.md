# Why Not Trust DIA Yet

`dia` is reviewable and externally confronted, but it is still blocked from
flagship outsider-auditable status.

## Current Blockers

- benchmark evidence tier is `curated_mini_study`, so DIA still lacks a
  flagship outsider-readable public package
- the current benchmark family is still anchored in a curated mini-study rather
  than a flagship public benchmark package
- comparator drift or missing external execution parity still materially limits
  this public workflow claim
- the current reproduction story still depends on execution steps that remain
  outside the repository proof boundary

## What Would Need To Change

- replace the current curated package with a flagship public package that
  carries real raw-data identity and harder scientific pressure
- expand DIA comparator pressure beyond checked-in reports so library and
  vendor drift can actually move release posture
- replace outside-repo execution steps with a tracked in-repo run or a stronger
  governed import bundle that outsiders can inspect as real proof
