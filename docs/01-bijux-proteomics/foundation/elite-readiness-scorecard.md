# Elite Readiness Scorecard

This scorecard is allowed to look only at shipped public-evidence substance.

It does not count files, documents, governance volume, or maintenance theater.

## Scoring Basis

- public benchmark package substance
- real runtime execution or explicit runtime block state
- external comparator confrontation
- curated knowledge sufficiency
- benchmark-backed recommendation posture
- lab-facing consequence packets

## Current Boundary

One outsider-auditable DDA family now exists, but repository-wide elite
language remains blocked until more than one flagship family survives the same
public package, runtime, comparator, knowledge, decision, and lab consequence
standard.

## Why The Repository Is Still Blocked

- DDA still carries advisory comparator-backed claim support and exploratory
  follow-up posture
- DIA is still a `curated_mini_study`
- LFQ, PTM, and targeted remain blocked by runtime gaps, refused claim support,
  or unjustified lab burden

## Rule

If a release note, README, or package page sounds more advanced than this
scorecard, the wording is wrong until the shipped evidence moves first.
