# Package Overview

`bijux-proteomics-lab` exists to turn plans and recommendations into assay work, outcome capture, and lab-facing loop control. The package is useful only when that
role stays narrow enough that a reviewer can say why it exists without naming
several different owners at once.

## What It Owns

- plan assay work
- capture and promote outcomes
- coordinate closed-loop lab-facing decisions

## What It Refuses

- evidence truth
- recommendation policy
- general execution orchestration

## First Proof Check

- `packages/bijux-proteomics-lab/src/bijux_proteomics_lab`
- `packages/bijux-proteomics-lab/tests`
- neighboring handbook branches once a change crosses the local role
