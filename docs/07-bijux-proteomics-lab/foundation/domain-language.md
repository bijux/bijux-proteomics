# Domain Language

Stable package language matters because `bijux-proteomics-lab` is easier to review when
its key terms do not drift into neighboring package vocabulary.

## Terms To Keep Stable

- `assay plan`
- `outcome promotion`
- `lab loop`

## Language Test

If a term makes it harder to say whether work belongs in `bijux-proteomics-lab` or in
bijux-proteomics-intelligence, change the term or move the work.

## First Proof Check

- this package handbook
- neighboring package handbooks for conflicting ownership language
