# Capability Map

The capability map lists the kinds of work `bijux-proteomics-lab` is allowed to do.
That list should make the package easier to defend in review, not broader by
default.

## Allowed Capability Classes

- plan assay work
- capture and promote outcomes
- coordinate closed-loop lab-facing decisions

## Disallowed Expansion

- evidence truth
- recommendation policy
- general execution orchestration

## First Proof Check

- [Package Overview](https://bijux.io/bijux-proteomics/07-bijux-proteomics-lab/foundation/package-overview/)
- [Ownership Boundary](https://bijux.io/bijux-proteomics/07-bijux-proteomics-lab/foundation/ownership-boundary/)
- the package source and tests that prove the claimed capability
