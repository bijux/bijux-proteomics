# Domain Language

Stable package language matters because `agentic-proteins` is easier to review when
its key terms do not drift into neighboring package vocabulary.

## Terms To Keep Stable

- `legacy surface`
- `canonical runtime`
- `compatibility bridge`

## Language Test

If a term makes it harder to say whether work belongs in `agentic-proteins` or in
bijux-proteomics-runtime, change the term or move the work.

## First Proof Check

- this package handbook
- neighboring package handbooks for conflicting ownership language
