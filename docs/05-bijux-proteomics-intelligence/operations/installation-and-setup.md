# Installation and Setup

Setup should get a reader to the package proof surface quickly instead of reproducing the whole repository in miniature.

## Operating Rules

- local setup should get you to candidate, policy, and report proof quickly
- use fixtures that expose recommendation ambiguity instead of only happy-path scoring
- keep runtime and lab execution machinery outside the core decision review loop

## First Proof Check

- `src/bijux_proteomics_intelligence/candidates/`, `judgment/`, and `posture/`
- `src/bijux_proteomics_intelligence/reviews/`, `interpretation/`, and `learning/`
- `packages/bijux-proteomics-intelligence/tests`
