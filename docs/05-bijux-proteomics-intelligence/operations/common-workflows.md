# Common Workflows

Common workflows should sound like the real jobs people do with the package, not generic process filler.

## Operating Rules

- compare recommendation changes against the evidence and contract inputs that drove them
- review whether candidate, judgment, or posture changes improve explanation as well as ranking
- update example outputs when a public recommendation artifact changes
