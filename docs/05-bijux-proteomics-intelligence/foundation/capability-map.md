# Capability Map

The capability map lists the kinds of work `bijux-proteomics-intelligence` is allowed to do.
That list should make the package easier to defend in review, not broader by
default.

## Allowed Capability Classes

- score and rank candidates
- evaluate scenarios and loops
- render explanations and reports for decisions

## Disallowed Expansion

- evidence truth and contradiction state
- durable program contracts
- execution orchestration

- [Package Overview](https://bijux.io/bijux-proteomics/05-bijux-proteomics-intelligence/foundation/package-overview/)
- [Ownership Boundary](https://bijux.io/bijux-proteomics/05-bijux-proteomics-intelligence/foundation/ownership-boundary/)
