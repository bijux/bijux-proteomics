# Domain Language

Stable package language matters because `bijux-proteomics-core` is easier to review when
its key terms do not drift into neighboring package vocabulary.

## Terms To Keep Stable

- `program contract`
- `lifecycle rule`
- `gate semantics`

## Language Test

If a term makes it harder to say whether work belongs in `bijux-proteomics-core` or in
bijux-proteomics-foundation, change the term or move the work.

## First Proof Check

- this package handbook
- neighboring package handbooks for conflicting ownership language
